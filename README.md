# The 1derful Festival

A single-page website for a fictional three-day beachfront music festival in Clearwater Beach, Florida, celebrating the one-hit wonders of the 90s and 2000s.

**Live site:** https://cwohr.github.io/1derful-festival/
**Case study:** [Behance](https://www.behance.net/gallery/248435195/GIT418-Final-Project)

## Features

- **Hero carousel:** Slick carousel with a fade transition and pause on hover
- **Artist lineup:** 22 artists loaded from a JSON file via AJAX, six at a time with a Load More button
- **Schedule:** day-by-day set times organized with jQuery UI tabs
- **FAQ:** common questions in a jQuery UI accordion
- **My Picks:** favorite artists, set times, and stages saved with Web Storage and restored on return visits

## Built With

HTML5 · CSS3 · JavaScript · jQuery · jQuery UI · Slick Carousel · AJAX/JSON · Web Storage

## Project Structure

- `index.html`: main page
- `css/style.css`: styles
- `js/main.js`: scripts
- `data/artists.json`: artist lineup data
- `assets/images/`: images
- `planning/wireframe.png`: planning wireframe
